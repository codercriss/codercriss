## About

<img src="./assets/terminal.svg" alt="Terminal session: whoami, stack, how I build, open to" width="100%" />

</div>

<br/>

I'm **Chris**, a **vibe coder**. I build web apps by describing what I want, working with AI as my pair programmer, and iterating until it feels right. No bootcamp, no classroom, just curiosity, late nights, and a lot of "why isn't this centered?" moments.

I started with **HTML and CSS**, got hooked on bringing pages to life with **JavaScript**, and now I use AI to move faster while learning **React** and understanding the code I ship.

<div align="center">

| 🧠 Right now | 🎨 What I enjoy | 🤝 Open to |
|:---:|:---:|:---:|
| Learning React components, props, state and hooks, not just generating them | Clean layouts, smooth interactions and responsive design | Collaborations, code reviews and open-source contributions |

<br/>

### What vibe coding means to me

| | |
|:--|:--|
| 💬 **I steer.** I describe the vision, AI helps write the code, and I guide the result. | 🔍 **I read everything.** I test and tweak what gets generated, so I actually learn from it. |
| 🐛 **I debug and take notes.** When something breaks, I fix it with AI and write down what went wrong. | 🚀 **I ship.** Real things out in the world matter more to me than writing every line by hand. |
